# Data Professional Survey Breakdown 

This project presents a detailed analysis of survey data collected from data professionals across the globe. The Power BI dashboard provides insights into their salaries, work-life balance, favorite programming languages, and more.

## Project Overview

The objective of this project was to analyze and visualize survey data from data professionals to answer key questions about:
- **Job Titles** and their corresponding **average salaries**
- **Countries** where survey respondents are located
- **Gender-based salary differences**
- **Favorite programming languages** among data professionals
- **Work-life balance** and **satisfaction with salaries**

The final interactive dashboard was created using Power BI and is published online for public viewing.

---

## Key Features

- **Average Salary by Job Title**: Highlights the average salary for roles such as Data Scientist, Data Engineer, Data Analyst, etc.
- **Country Distribution**: A treemap visualization showing the countries of survey participants, with the majority from the United States and India.
- **Favorite Programming Languages**: Python emerged as the top choice, followed by R, C/C++, and JavaScript.
- **Average Salary by Gender**: Provides insights into gender-based salary disparities.
- **Satisfaction Scores**:
  - **Salary Satisfaction**: Average rating on a scale of 1–10.
  - **Work-Life Balance Satisfaction**: Average rating on a scale of 1–10.
- **Summary Stats**:
  - Total survey responses: **502**
  - Average age of respondents: **29.89 years**

---

## Insights

1. **Data Scientist** roles report the highest average salaries, followed by Data Engineers and Data Architects.
2. The **United States** and **India** dominate the survey responses, showcasing global interest in data-related fields.
3. **Python** is the most popular programming language, highlighting its dominance in data science and engineering.
4. Respondents are generally more satisfied with their **work-life balance** than their **salary**.
